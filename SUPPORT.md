# Support

## Where to ask

- **Documentation** — <https://docs.outerlayer.ai>. Start here; most setup and
  configuration questions are answered there.
- **Bugs and feature requests** — [open an issue](../../issues/new/choose).
  Bug reports need a version or commit, whether you are on the cloud or
  self-hosting, and steps to reproduce. The issue form asks for these.
- **Questions about using OuterLayer** — open an issue too. There is no separate
  forum yet, and a question in the open helps the next person who has it.
- **Security vulnerabilities** — do *not* open an issue. See
  [SECURITY.md](SECURITY.md) for the private channels.
- **Anything commercial** — billing, the cloud service, enterprise licensing for
  the `ee/` directories — email <hello@outerlayer.ai>.

## What to expect

This project is maintained by a small team.

- **There is no SLA on the open-source project.** Issues and pull requests are
  read, but nothing here promises a response within a given window, and an issue
  going quiet is not a decision — feel free to bump it.
- **Security reports do have targets.** Acknowledgement within 3 business days,
  an initial assessment within 10. Those are in [SECURITY.md](SECURITY.md), and
  they apply whether you are a customer or not.
- **The cloud service is separate.** Support commitments for
  [OuterLayer Cloud](https://app.outerlayer.ai) come from the plan you are on, not
  from this repository.

Before opening an issue, please search the existing ones — including closed
ones, which often carry the answer and the reason.
